# Vídeo, animação e jogos 3D com Claude Opus 5.6

## 🍌 Introdução

Uma seleção de vídeos, animações e jogos 3D feitos com código que a comunidade atribui ao Claude Opus 5.6. As publicações apareceram durante um teste limitado.

<a id="overview"></a>

## 📊 Visão geral

**10 casos · 7 exemplos de vídeo e animação · 3 exemplos de jogos 3D.**

> [!NOTE]
> Cada caso registra fonte, conta, data e evidência. Um vídeo de gameplay ou um trailer, por si só, não comprova que o jogo pode ser jogado.

<a id="quick-start"></a>
