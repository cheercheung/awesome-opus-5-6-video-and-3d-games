# awesome-opus 5.6 for video and 3d games

<a id="introduction"></a>

## 🍌 Introdução

Coleção independente de curtas, animações e jogos 3D. Os rótulos distinguem prompts publicados de demonstrações. As publicações apareceram durante um teste limitado.

Cada caso registra fonte, conta, data e evidência. Um vídeo de gameplay ou um trailer, por si só, não comprova que o jogo pode ser jogado.
