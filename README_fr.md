# Vidéo, animation et jeux 3D avec Claude Opus 5.6

## 🍌 Introduction

Une sélection de vidéos, d’animations et de jeux 3D réalisés en code que la communauté attribue à Claude Opus 5.6. Les publications datent d’une phase de test limitée.

<a id="overview"></a>

## 📊 Aperçu

**10 cas · 7 exemples de vidéo et d’animation · 3 exemples de jeux 3D.**

> [!NOTE]
> Chaque cas indique la source, le compte, la date et les éléments observables. Une capture de jeu ou une bande-annonce seule ne prouve pas que le jeu est jouable.

<a id="quick-start"></a>

## ⚡ Prise en main

Choisissez un cas dans le sommaire puis ouvrez la publication d’origine pour voir l’exemple et lire son contexte.
