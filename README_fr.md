# awesome-opus 5.6 for video and 3d games

<a id="introduction"></a>

## 🍌 Introduction

Collection indépendante de courts métrages, d’animations et de jeux 3D. Les étiquettes distinguent les consignes publiées des démos. Les publications datent d’une phase de test limitée.

Chaque cas indique la source, le compte, la date et les éléments observables. Une capture de jeu ou une bande-annonce seule ne prouve pas que le jeu est jouable.

## ⚡ Prise en main

Choisissez un cas dans le sommaire puis ouvrez la publication d’origine pour voir l’exemple et lire son contexte. [Sommaire](#menu)
