# Contributing

Open an issue to suggest a case or correct an attribution. Include the original public post, the posting account, the date, the model named in the post, and the evidence available. Tell us whether a game link opens a runnable build, a gameplay recording, or a trailer.

For a pull request, create a branch from `main` and follow the [maintenance guide](docs/maintenance.md). Local editing requires a Markdown editor, Git, and Python 3 for checking the JSON. Keep citations, stable case numbers, and translations synchronized.

Repository-authored text and cover art use [CC BY 4.0](LICENSE). Linked posts and media remain under their respective terms.
