# Claude Opus 5.6 video, animation, and 3D games

## 🍌 Introduction

A curated collection of code-driven video, animation, and 3D games attributed to Claude Opus 5.6 by community posters. The posts were shared during limited testing.

<a id="overview"></a>

## 📊 Overview

**10 cases · 7 video and animation examples · 3 3D game examples.**

> [!NOTE]
> Each entry records a source, posting account, date, and the evidence shown. A gameplay clip or trailer alone does not establish playability.
