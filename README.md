# awesome-opus 5.6 for video and 3d games

<a id="introduction"></a>

## 🍌 Introduction

Independent collection of short films, animations, and 3D games. Case labels distinguish full or explicitly scoped published prompts from demos. The posts were shared during limited testing.

Each entry records a source, posting account, date, and the evidence shown. A gameplay clip or trailer alone does not establish playability.
