# awesome-opus 5.6 for video and 3d games

<a id="introduction"></a>

## 🍌 简介

独立收录短片、动画和 3D 游戏。案例标签区分公开提示词与作品展示。 原帖发表于灰测期间。

每个案例标注来源、账号、日期和可见证据。试玩录屏或预告片本身无法证明作品可玩。
