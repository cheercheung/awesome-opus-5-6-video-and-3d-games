# awesome-opus 5.6 for video and 3d games

<a id="introduction"></a>

## 🍌 簡介

獨立收錄短片、動畫和 3D 遊戲。案例標籤區分公開提示詞與作品展示。 原始貼文發表於灰度測試期間。

每個案例標示來源、帳號、日期與可見證據。單靠遊玩錄影或預告片無法證明作品可玩。
