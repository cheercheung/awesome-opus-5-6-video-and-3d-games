# awesome-opus 5.6 for video and 3d games

<a id="introduction"></a>

## 🍌 Введение

Независимая подборка короткометражек, анимации и 3D-игр. Метки различают опубликованные промпты и демо. Публикации появились в период ограниченного тестирования.

В каждом примере указаны источник, аккаунт, дата и доступные свидетельства. Запись игры или трейлер сами по себе не подтверждают играбельность.

<a id="quick-start"></a>

## ⚡ Быстрый старт

Выберите пример в оглавлении и откройте исходную публикацию, чтобы увидеть результат и описание. [Содержание](#menu)
