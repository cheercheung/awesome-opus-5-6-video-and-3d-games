# awesome-opus 5.6 for video and 3d games

<a id="introduction"></a>

## 🍌 Einführung

Unabhängige Sammlung von Kurzfilmen, Animationen und 3D-Spielen. Die Kennzeichnung unterscheidet veröffentlichte Prompts von Demos. Die Beiträge erschienen während eines begrenzten Tests.

Jeder Eintrag nennt Quelle, Konto, Datum und Belege. Ein Mitschnitt oder Trailer allein belegt keine Spielbarkeit.
