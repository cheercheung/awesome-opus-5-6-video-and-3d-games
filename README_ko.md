# Claude Opus 5.6 영상, 애니메이션, 3D 게임

## 🍌 소개

커뮤니티에서 Claude Opus 5.6으로 만들었다고 소개한 코드 기반 영상, 애니메이션, 3D 게임을 모았습니다. 게시물은 제한 테스트 기간에 공개되었습니다.

## 📊 개요

> [!NOTE]
> 각 사례에는 출처, 게시 계정, 날짜, 확인 가능한 증거를 기록했습니다. 플레이 영상이나 예고편만으로 실제 플레이 가능 여부를 확인할 수는 없습니다.
