# awesome-opus 5.6 for video and 3d games

<a id="introduction"></a>

## 🍌 소개

단편 영상, 애니메이션, 3D 게임을 모은 독립 컬렉션입니다. 공개 프롬프트와 데모를 구분합니다. 게시물은 제한 테스트 기간에 공개되었습니다.

각 사례에는 출처, 게시 계정, 날짜, 확인 가능한 증거를 기록했습니다. 플레이 영상이나 예고편만으로 실제 플레이 가능 여부를 확인할 수는 없습니다.
